description=[hr][/hr]

description=A [b]required UI library[/b] shared by Minidoracat mods. It [b]adds no gameplay content by itself[/b]; everything you see comes from the mods that depend on it.
description=
description=✨ [b]Family toolbar[/b]: the buttons of all family mods sit in one collapsible vertical strip; press the "." key to open it.
description=
description=[h2]📦 Who needs it[/h2]
description=These mods list it under Required Items — subscribe if you use any of them:
description=[list]
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3763913359]Minidoracat MiniMap for B42[/url] (its add-ons such as MOD Maps, Zones and MOD Compatibility need it indirectly through MiniMap)
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3792675881]Minidoracat MiniMap - AutoDrive for B42[/url]
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3779823349]Minidoracat Cleaner for B42[/url]
description=[*] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3789836823]Minidoracat Notice Board for B42[/url]

description=[/list]
description=If you use none of them, you don't need to enable it. Supports Build 42.20.1 or later, singleplayer and multiplayer.
description=[list]
description=[*] [b]Add/remove mid-save:[/b] safe either way; when removing it, also remove every mod that requires it

description=[/list]

description=[h2]🖥️ Load order & multiplayer[/h2]
description=Place it [b]above every mod that depends on it[/b] in your mod list. On multiplayer, both server and clients need it: add [b]Mods=[/b]MinidoracatUIFor42 and [b]WorkshopItems=[/b]3789836701 to the server ini.
description=
description=[h2]⚠️ Where to report problems[/h2]
description=This page only covers the library itself. If a map doesn't show, a feature misbehaves or an error pops up, please report it on [b]that mod's page[/b] (e.g. mod maps missing on the minimap → MiniMap or MOD Maps page); errors from other authors' mods go to those authors. Not sure which mod it is? Ask on Discord with your console.txt.
