description=[h2]✨ What is this[/h2]
description=Shared UI library for the Minidoracat mod series: themed color palettes (dark / light), rounded-corner window skins, shared monochrome icons, floating buttons, toast notifications and other reusable components.
description=
description=This mod [b]does not add any gameplay content by itself[/b] — it is a base library used by other mods. Its visible effects depend entirely on the mods that use it.
description=
description=[h2]👥 Who needs this[/h2]
description=[list]
description=[*] Subscribe only when another mod lists it under Required Items
description=[*] If none of your mods depend on it, you can leave it disabled
description=[/list]
description=
description=[h2]🧰 What it provides (for mod developers)[/h2]
description=[list]
description=[*] [b]Theme system[/b]: token-based palettes with dark / light variants, per-mod overrides
description=[*] [b]Rounded skin[/b]: engine-native 9-slice rounded rendering with a safe rectangular fallback when textures are missing — windows never fail to open
description=[*] [b]Shared widgets[/b]: floating button (drag + position memory), toast notifications (shared stack across mods)
description=[*] [b]Shared painters[/b]: stateless pill, toggle, and slider visuals that dependent mods can compose without replacing their interaction logic; missing textures safely fall back to basic shapes
description=[*] [b]Shared icons[/b]: 20 monochrome line icons (sidebar, folder, document, expand/collapse, search, layers, pin, globe, lock, close, locate, copy, etc.) plus 13 solid silhouettes (house, skull, paw print, steering wheel and chicken/cow/pig/sheep/deer/rabbit/raccoon/rodent/turkey), tinted to match the active palette; callers fall back to their text markers when an icon asset is missing
description=[*] [b]Virtual list[/b]: large tables (trading/auction-style UIs) only build visible rows
description=[*] [b]Versioned API[/b]: dependent mods declare the API revision they need, so library updates never silently break them
description=[/list]
description=
description=[h2]⚠️ Load order[/h2]
